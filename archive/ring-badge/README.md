# Archived — the ring badge (first take)

The first build of this tool was a port of `badge.hatchconference.com`: six tilted
cylindrical rings in WebGL, animated on an 8-second loop. It was replaced by the
"I am going" poster in `assets/js/poster.js`.

Kept because it works and nothing else has a copy. `badge.js` + `ringgl.js` +
`textures.js` are self-contained apart from `editions.js` and the old `main.js`
wiring (name / role / company / edition / photo / photoZoom).
